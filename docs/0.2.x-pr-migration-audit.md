## Current merge guidance

The safe 0.2.x migration set is #54, #81, #85, #89, #91, #93, #97, #98, #101, #108, #111, and #116 as current-architecture migrations or absorbed behavior. The launcher-only portion of #120 is suitable for pre2, but its PP runtime combinations are not promoted. #71 remains suitable for continued validation because its SM75 FP8 format selection is implemented, while its long-context quality claim still requires target-GPU evidence. #78 is wired into the 0.2.x metadata and mixed-batch paths without forward-time FlashInfer planning, but remains an experimental performance route until the target-GPU A/B is complete. #72 remains a deployment design reference rather than a code cherry-pick.

## Validation boundary

The available development host is not the 0.2.x target host: it has CUDA 12.8, GCC 13, an older Linux kernel, and a CMP 90HX rather than dual RTX 2080 Ti. The Python parser, serving, and TurboQuant planning regressions can run locally, but they do not establish CUDA 13, SM75, FlashQLA, CUDA Graph, TurboQuant quality, or throughput evidence. Those claims require the target CUDA 13/PyTorch 2.13/GCC 15 environment and the documented dual-2080-Ti benchmark procedure.
